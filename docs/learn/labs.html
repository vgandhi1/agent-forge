Part 03 · Hands-on

Run it yourself

Reading is half of it. Run these in order — each lab maps a concept to a real command. Click any command to copy. Use --dry-run first to preview without API calls.

0

Set up

Install deps and confirm the toolchain. Pick a provider.
bash
cd agent-forge
uv sync                                  # install
export ANTHROPIC_API_KEY=sk-...          # or: AGENTFORGE_LLM_PROVIDER=ollama
uv run python main.py --help
1

Preview a plan · Theory ③

See the phases without spending a token — the planning surface, dry.
bash
uv run python main.py --preset full --adaptive --dry-run \
  --goal "A REST API to track factory machine downtime"
2

Greenfield build · Theory ①②⑤

Watch the full org run the loop end-to-end in the sandbox.
bash
uv run python main.py --preset full \
  --goal "Build DailyEase task + habit tracking endpoints"
uv run python main.py --list-artifacts   # inspect what it produced
3

Operate on YOUR repo · Theory ②⑥

Point it at an existing project and let it debug a failing test — grounded, gated.
bash
uv run python main.py --target-repo /path/to/app \
  --preset debug --adaptive --strict-review \
  --goal "Reproduce and fix the failing checkout test"
4

Factory data + AI · Theory ②④

Run the data/ML team — the builders generate fixtures and self-verify.
bash
uv run python main.py --preset factory --adaptive \
  --goal "Predictive-maintenance pipeline for pump vibration data"
5

Ship with the gate · Theory ⑥

Turn on the deploy gate + commit-on-a-branch. Open --web for live progress.
bash
uv run python main.py --preset harden --deploy-gate \
  --deploy-commit --deploy-branch agentforge/harden --web \
  --goal "Production-readiness pass: tests, security, drift"
Watch the loop adapt. Add AGENTFORGE_JSON_LOG=1 to emit one JSON event per line (phase_complete, review_verdict, pytest_result) — the same stream the Web UI parses into live progress.
