What actually makes a system "agentic"?

A chatbot answers. A workflow runs fixed steps. An agentic system pursues a goal: it decides what to do next, acts through tools, observes the result, and adapts — looping until the goal is met or it knows it is stuck. Four properties separate it from a script:

01

Goal-directed autonomy

Given an objective, it chooses steps itself rather than following a hard-coded list.

02

Tool use / grounding

It affects the real world — reading files, running tests, editing code — not just emitting text.

03

Feedback & adaptation

It observes outcomes (a failing test, a reviewer rejection) and changes course.

04

Bounded self-direction

It knows when to stop, escalate, or defer — guardrails keep autonomy from becoming chaos.

Mental model. An agent = while not done: state → decide → act → observe. Everything else — planning, memory, multi-agent orgs — is structure layered on that loop to make it reliable at scale. This guide teaches each layer twice: the idea, then the code.
