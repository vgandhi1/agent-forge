Appendix

Glossary

Tool loop
The multi-turn call→act→observe cycle. → BaseAgent.run_tool_loop
Grounding
Tying the agent to reality via tools so it verifies instead of asserting. → exec_tools, phantom_imports
Adaptive / re-planning
Choosing & revising the phase sequence at runtime. → --adaptive, lead._plan_phases
Context budget
Curating working memory so the window doesn't overflow. → rolling_state_block, _compact_messages
Scope lock
Deferring out-of-scope work to a Known-Gaps log instead of expanding the task.
Deploy gate
verify → human sign-off → commit. The brake before shipping.
Escalation
Routing a decision the agent shouldn't make to a human; safe-pauses on timeout.
Reviewer
An independent agent that reads the real files and returns approve/reject — silence ≠ approval.
